# MSP Ticket Checklist

- [ ] Customer identified.
- [ ] Requester authorized.
- [ ] Request summarized.
- [ ] Risk class assigned.
- [ ] Urgency assigned.
- [ ] Missing info listed.
- [ ] Customer approval requirement identified.
- [ ] Execution plan written.
- [ ] Verification plan written.
- [ ] Rollback plan written.
- [ ] Customer response drafted.
- [ ] Closeout drafted after verification.
