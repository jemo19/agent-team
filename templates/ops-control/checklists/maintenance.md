# Maintenance Checklist

## Before

- [ ] Goal/ticket exists.
- [ ] Scope confirmed.
- [ ] Risk class set.
- [ ] Backup status checked.
- [ ] Maintenance window approved if needed.
- [ ] Exact commands reviewed.
- [ ] Rollback plan written.
- [ ] Verification plan written.

## During

- [ ] Pre-check captured.
- [ ] Change executed one server/system at a time.
- [ ] Output captured.
- [ ] Errors triaged before continuing.

## After

- [ ] Health checks passed.
- [ ] Logs checked.
- [ ] Monitoring checked.
- [ ] Evidence updated.
- [ ] Customer/internal closeout drafted.
